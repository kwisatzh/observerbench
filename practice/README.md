# Open practice tasks

These tasks give immediate local feedback. Their targets are public, so the
scores are for learning and development rather than the sealed leaderboards.

| Task | Model access | Primary lesson |
| --- | --- | --- |
| [Safety tutorial](../site/try/) | None | Better classification can produce a worse budgeted safety decision. |
| [Qwen2.5-7B Copy-v2, budget 40](qwen_copy_v2_b040/) | Cached measurements only | Prediction error and selected-action loss are different tests. |

Run both examples from the repository root:

```bash
make demo
```
